# AirlineManagement — ЛР №2

WinForms на .NET 8, EF Core Code First, PostgreSQL и Serilog. DBeaver — клиент для просмотра PostgreSQL, не сервер базы данных.

## Как запустить в Visual Studio

1. Установите **.NET 8 SDK** (он также устанавливает Windows Desktop Runtime). Запустите PostgreSQL. Создавать таблицы в DBeaver вручную не нужно.
2. В папке проекта рядом с `.csproj` создайте `appsettings.Local.json`. Файл исключён из Git. Пример для локального PostgreSQL (подставьте свои имя пользователя и пароль):

   ```json
   {
     "ConnectionStrings": {
       "Airline": "Host=localhost;Port=5432;Database=airline_lab2;Username=postgres;Password=ВАШ_ПАРОЛЬ"
     }
   }
   ```

   Вместо файла можно задать переменную окружения `ConnectionStrings__Airline`. Не записывайте пароль в общий `appsettings.json`.
3. Откройте `AirlineManagement.slnx`, выберите `AirlineManagement` как запускаемый и как проект по умолчанию в **Сервис → Диспетчер пакетов NuGet → Консоль диспетчера пакетов**. Выполните `Update-Database`. Миграция `InitialCreate` уже в репозитории: повторять `Add-Migration` не нужно. Если у пользователя PostgreSQL нет права создавать базы, сначала создайте пустую `airline_lab2` через DBeaver под администратором и назначьте её владельцем пользователя приложения.
4. Запустите приложение. Для DBeaver используйте тот же хост, порт и имя базы `airline_lab2`; раскройте `Schemas → public → Tables`. После миграции будет также таблица `__EFMigrationsHistory`.

## Что показать на сдаче

- Добавить, отредактировать и удалить запись в справочниках самолётов, сотрудников и рейсов.
- Записать выполнение рейса: выбрать рейс, самолёт, ответственного сотрудника и дополнительных членов экипажа. Запись о выполнении и строки `FlightExecutionCrewMembers` сохраняются в одной транзакции. Ответственный сотрудник включается в экипаж автоматически.
- Добавить запись о продаже билетов и убедиться, что операции видны после перезапуска.
- Проверить записи об операциях в `Logs/airline-*.log` относительно рабочего каталога приложения. Папка `Logs` исключена из Git.
